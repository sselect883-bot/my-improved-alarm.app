# Android版 自主制作アラーム

既存のHTML/CSSをアプリ内のWebViewに同梱し、KotlinのAlarmManager.setAlarmClockで予約します。
GitHub Pages版のコードと動作はそのままです。URLをChromeで開くだけでは、スリープ中の鳴動には対応しません。
Android 8.0以降向けです。iPhone用アプリは含みません。

## APKの入手・インストール

1. GitHubの「Actions」→「Android APK」→対象ブランチの成功した実行を開きます。
2. Artifactsの「my-alarm-android-debug」をダウンロードし、ZIPからapp-debug.apkを取り出します。GitHubへのログインが必要です。
3. AndroidへAPKを転送して開き、必要に応じてそのファイルを開くアプリからのインストールを許可します。
4. ホーム画面またはアプリ一覧の「自主制作アラーム」を開きます。
5. 上部の「アラーム許可」「通知許可」を設定します。アラーム音量を上げ、通知チャンネルも有効にしてください。
6. 時刻を選び「アラーム追加」。予約一覧の日付・時刻を確認してください。
7. 鳴ったら通知の「停止」、またはアプリの「アラーム停止」で止めます。

このAPKは動作確認用のdebug署名です。CIのdebug署名は継続更新用として保証されません。
署名が異なるAPKは上書きできず、アンインストールすると予約が消えます。
配布版では固定の署名鍵を安全に管理してreleaseビルドしてください。

## 予約・動作

- 次に来る指定時刻に一度だけ鳴動します。同じ時刻を過ぎていれば翌日です。
- 予約は端末内に保存され、画面遷移やアプリの通常終了では消えません。
- 画面オフ・Doze中もOSが予約を実行し、鳴動時だけフォアグラウンドサービスを動かします。
- 音声は同梱のalarm.mp3をループ再生し、端末のアラーム音量を使います。
- 同時に複数の予約が鳴った場合は1つの音にまとめます。停止しても未来の予約は残ります。
- 鳴動は最大10分で自動停止します。バイブレーションや全画面の自動表示は実装していません。
- 再起動・アプリ更新後は未来の予約を復元します。電源オフ中に過ぎた予約は鳴らさず削除します。
- 再起動後の復元は最初のロック解除後です。解除前の鳴動には対応していません。
- 手動の日時・タイムゾーン変更時は、各予約を新しい現地時刻の次の指定時刻に設定し直します。
- 「強制停止」、権限の取り消し、端末の電源オフ、アラーム音量0、集中モードの設定やメーカー独自の制限では鳴らない場合があります。
- 許可を取り消すとOS側の予約が解除されるため、再度アラーム許可を与えてください。

## Android Studio / コマンドでビルド

Android Studioでこのandroidフォルダを開き、JDK 17・Android SDK 35を用意します。
Gradle 8.11.1、Android Gradle Plugin 8.9.2、Kotlin 2.1.20を固定しています。
Gradle wrapperは同梱していないため、コマンドラインではGradle 8.11.1を用意してください。

```sh
gradle :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
gradle :app:connectedDebugAndroidTest
```

ルートのHTML/CSSとalarm.mp3はビルド時に自動で取り込まれます。
Android用のJavaScriptはapp/src/main/web/native.jsです。Web画面のタイマーは鳴動を担当しません。
ネイティブ連携は同梱したページに限定し、外部ページやファイルアクセスを遮断しています。

## 実機での確認（必要）

CIのビルド・lint・時刻計算テスト・エミュレータの予約登録テストに加えて、次をAndroid実機で確認してください。

1. 2〜3分後に予約 → ホームに戻る → 画面を消す → 時刻どおりに鳴る → 通知で停止。
2. 複数の予約を追加し、1件削除しても残りが鳴る。
3. アプリ一覧からの通常のタスク除去後も鳴る（設定の「強制停止」とは別）。
4. 再起動・ロック解除後に未来の予約が鳴る。
5. アラーム許可と通知許可を拒否すると追加が失敗し、許可後に追加できる。
6. Doze状態でのテスト。開発用端末を接続して以下を使用し、終了後は必ず解除。

```sh
adb shell dumpsys battery unplug
adb shell dumpsys deviceidle force-idle
# 予約時刻の鳴動と停止を確認
adb shell dumpsys deviceidle unforce
adb shell dumpsys battery reset
```
